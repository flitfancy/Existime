# map v2 外部电池版

外部1.8–5V设计输入，经SW3正极硬开关、TPS631000升降压输出3.3V。板上无充电和电池保护，使用锂电时由外部模块负责。首版固件默认两节碱性AA/AAA。

- [完整丝印](full-silkscreen)：可编辑原生工程及PCB预览；Gerber见对应版本的`03-PCB制造`目录。
- [无背面丝印](no-back-silkscreen)：无背面丝印的可编辑工程及预览，正面及电路保持。
- [BOM.csv](../../02-BOM/v2/BOM.csv)：UTF-8参数物料表；LED、R/C/L等不限定料号，芯片及机械件保留型号。
- [合并Excel物料表](../../02-BOM/map-BOM.xlsx)：v1/v2各一张表；选料规则见[物料表说明](../../02-BOM/BOM说明.md)。
- [map-v2-bom-native.csv](../../02-BOM/v2/map-v2-bom-native.csv)：原生BOM（UTF-16、Tab分隔）。
- [map-v2-cpl-mm.csv](../../04-装配资料/v2/map-v2-cpl-mm.csv)：原生坐标文件，单位mm，保留EDA原点与有符号坐标。

`pcb-preview.webp`为EDA多层叠加预览；无背面丝印版仍会显示正面地图、位号和铜走线。其工程内缩略图与外部预览均已重新渲染，背面山林装饰图案已移除。

两种丝印共用BOM、器件坐标及对应硬件固件。无背面制造包仅从完整原生Gerber中去掉GBO，其他成员逐字节相同；源工程只删除背面IMAGE对象。校验见[整理记录](../../05-核对记录/packaging-check.json)。

BOM原生不包含J2/SWD排针和TP1/TP2测试焊盘；坐标文件是否包含这些非BOM对象已单独核对，不将其自动视为需要装配的物料。参数表用于选料；自动PCBA订料前需要为参数件确定实际采购物料并核对封装、极性。

当前原生DRC为0；这不代表板厂DFM、热/EMI或整机装配已完成。

LP1使用项目内修正封装：0.8×2.0mm焊盘、1.2mm内间隙，不要盲目从原库L1008刷新覆盖。新增输入禁铺铜覆盖正极附近到负极之间，负极保留接地。完整供电与测试边界见[2.0说明](../../04-装配资料/使用说明/v2-power.md)。
