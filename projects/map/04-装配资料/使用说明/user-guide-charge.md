# map charge 使用说明

## 按键

**0 = SW2 / PA1，1 = SW1 / PA0。**

| 状态 | 操作 | 结果 |
|---|---|---|
| 正常指南针 | 短按0 | 逐颗显示电量，约3秒后自动回指南针 |
| 正常指南针/电量 | 同时按住0、1满3秒，松开 | 进入编辑菜单 |
| 编辑菜单 | 短按0 / 短按1 | 磁力校准 / 省份灯编辑 |
| 省份灯编辑 | 短按0 / 短按1 | 上一个 / 下一个，首尾循环 |
| 省份灯编辑 | 按住0满1秒，在3秒前松开 | 熄灭当前省份灯 |
| 省份灯编辑 | 按住1满1秒 | 点亮当前省份灯 |
| 菜单、灯编辑、校准采集或对北 | 单独按住0满3秒 | 退出；未完成的校准不覆盖旧参数 |
| 校准正在保存 | 无需按键 | 保存并校验成功后自动回指南针 |

34颗省份灯按实际PCB的X坐标递增，见 [province-order.csv](../../06-固件源码/firmware/charge/province-order.csv)。第一次全灭，之后恢复最近保存状态。闪烁光标不改变保存的亮灭设置。按键消抖30ms，组合键不泄漏单键动作。

SW3开启且充电状态有效时，正常指南针及电量页的中心D43约3.2秒一轮慢呼吸；无充电状态时常亮。菜单、编辑和校准流程保持原闪烁反馈。SW3关闭会切断主控和灯的电源，固件无法在硬件关机时显示中心充电灯。

## 校准

1. 完成电池、外壳装配后，远离磁铁、音箱、钢桌面和带磁工具。双键长按3秒，松开，短按0进入采集。
2. 缓慢翻转、旋转，使正面、背面、上沿、下沿、左沿、右沿分别朝上，并在不同姿态下继续转动。至少采集20秒、300个合格样本，六个姿态及三个磁轴的跨度均合格后，八个方向灯全亮。长按1满1秒并松开进入对北。
3. 顶部 D35（R3对应）闪烁。将板子元件面朝上、大致平放，上沿对准指定正北。长按1满1秒并松开，保持不动约2秒，取得40个稳定样本。
4. 固件自动保存并逐字节核对 EEPROM。**保存成功后直接回正常指南针，中心灯常亮，无需再长按0。** 转换时要求按键全部松开，避免松手被当作新操作。保存失败会中心快闪并限速重试，不能把未保存状态当作完成。

对北超时或姿态不合格回到对北等待；采集和对北阶段取消时保留之前的校准。采用三轴硬铁偏移和各轴比例补偿，不含完整软铁交叉轴矩阵。参考北向由用户指定，固件不自动取得位置或磁偏角。

## 指南针

- D35～D42依次为北、东北、东、东南、南、西南、西、西北，表示**地图上沿当前朝向**。本版修正了旧版东西反向：相对已保存的北向零点按顺时针输出，原校准参数兼容，不需要重新校准。
- 每个方向窗口 **±3°，包含边界**；其他角度方向环熄灭。滤波后连续3个新磁力样本进入同一窗口才亮，离开窗口立即取消，不扩大点亮范围。
- 磁力计20Hz、加速度计50Hz，定点CORDIC，无浮点运行时。要求元件面朝上、偏离水平约15°以内。
- 未校准、倾斜过大、剧烈运动、磁场明显异常或数据过期时不输出方向。中心灯常亮只表示正常页面。
- ±3°是显示窗口，不是已验收的绝对精度；需在实际装配和使用环境中旋转验证。

## 电量与充电提示

短按0后，从 D42/NW/12.5% 起，每100ms增加一颗，依次 D41、D40……D35/N/100%。显示总时长仍约3秒；省份灯设置不变，中心灯按当前充电状态显示。

| 状态 | 方向环 |
|---|---|
| 电量1～7档，无充电状态 | 逐颗点亮到当前档位，保持 |
| 电量1～7档，充电状态有效 | 已有档位常亮，**下一颗呼吸** |
| 显示8档，充电状态有效 | 前7颗常亮，最后 D35 呼吸；不会绕回第一颗 |
| 检测到充电完成 | 中心与八颗方向灯全部常亮约3秒，之后恢复正常页面，退出呼吸 |
| 0档 | 无充电状态时 D42慢闪，有充电状态时 D42呼吸 |
| 采样无效或过期 | 八颗一起闪，不伪造电量 |

呼吸包络约1.6秒，使用独立方向灯扩展器0x20的软件PWM，载波目标100Hz；其余省份灯不参与调制。中心D43独立使用PA8/AF2的TIM1_CH1，目标1kHz硬件PWM，约3.2秒包络；常规传感器采样和I2C事务不会暂停PWM载波。电量页面暂缓罗盘采样和灯驱动轮询回读，为PWM留出总线时间，退出后重新取得新样本，不显示缓存航向。I2C事务在主循环串行执行，未放入中断。

充电完成提示要求开机时先观察到充电状态，随后USB保持有效、CHG连续高约1秒，过滤短暂跳变及2Hz定时故障信号。确认期间延续呼吸；确认后中心和八方向常亮3秒，省份灯保持设置，再恢复正常页面。每次USB连接只提示一次，拔USB不触发新的完成提示。编辑/校准期间收到完成事件会延后到正常或电量页；提示过程中进入编辑也会延后，返回后显示完整3秒。该事件不写EEPROM，硬件关机期间发生的完成事件不能由停机的固件记录。

**充电提示依据PGOOD_N和CHG_N状态，不测量实际充电电流。** BQ24074在温度检测异常、充电暂停时CHG仍可保持低，因此呼吸灯不能证明有持续电流流入电池。实际电流可按ISET监测和外部仪表核对；设计R53=1.8kΩ时，Icharge(mA)约为R53两端电压(V)×222。

PA3采样R57/R58的100k/100k分压，C17=100nF；12位ADC，HCLK/4、长采样、8组均值，每秒更新。内部VREFINT通道10，工厂校准半字0x1FFF756A、标定供电3000mV。利用VREFINT恢复实际VDDA，再算电池电压，没有人为增加补偿系数。

容量采用通用单节4.2V锂电的电压近似：3.30V=0%、3.50V=5%、3.60V=10%、3.67V=20%、3.74V=40%、3.80V=60%、3.90V=75%、4.00V=85%、4.10V=95%、4.20V=100%。不等同于库仑计；充电和负载会影响电压。USB接入时仅靠BAT电压也不能可靠识别是否真的装了电池。

## 保存和电源

EEPROM布局保持兼容：两个128字节槽，56字节记录、序号和CRC32；8字节页写、先撤销新槽、最后提交标志并读回。正在保存时的新修改会再提交一次。普通灯设置通常几百毫秒保存；断电会保留最近一次完整记录。61个断电位置为主机模型验证，实板已验证实际写入、读回与重启恢复，未做硬件断电时序遍历。

SW3是硬件开关，控制U2稳压器及U11采样开关；关闭后U9充电和U10保护上游仍可能带电。U9设定充满4.2V、典型充电约0.49A，电池须允许该电流。电池负极接B−，经U10/Q1保护后才到系统GND。普通可调电源接电池端时，不与USB充电输入并接。当前供电范围与验证边界见 [验证记录](../../05-核对记录/validation-charge.md)。
