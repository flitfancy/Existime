# Flitime 接口

以下针脚取自本次原生工程读取。JIN只接外部稳压3.3V和保护后的系统GND；T3lite、供电电池及USB转接小板为外部配套。

| 接口 | 针脚 | 网络 |
| --- | --- | --- |
| JIN | 1 | 3V3 |
| JIN | 2 | GND |
| JDBG | 1 | USB_DM |
| JDBG | 2 | USB_DP |
| JDBG | 3 | GND |
| JDBG | 4 | MCU_BOOT_N |
| JDBG | 5 | MCU_EN |
| JLCD | 1 | 3V3 |
| JLCD | 2 | GND |
| JLCD | 3 | LCD_CS |
| JLCD | 4 | LCD_RST |
| JLCD | 5 | LCD_DC |
| JLCD | 6 | LCD_SPI_MOSI |
| JLCD | 7 | LCD_SPI_SCK |
| JLCD | 8 | LCD_BL |
| JLCD | 9 | LCD_SPI_MISO |
| JLCD | 10 | LCD_SPI_SCK |
| JLCD | 11 | LCD_TOUCH_CS |
| JLCD | 12 | LCD_SPI_MOSI |
| JLCD | 13 | LCD_SPI_MISO |
| JLCD | 14 | LCD_TOUCH_INT |

JDBG为五个裸焊线孔，连接USB D−/D+、共地及BOOT/EN控制；USB小板的5V不接主板3V3。JLCD为14针SPI屏幕接口，实际模块针序、驱动芯片、3.3V供电、背光及装配关系仍需实物核对。

当前未提供固件，以上是接线定义，不代表已经完成烧录或整机功能验证。
