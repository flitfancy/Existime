# 硬件项目

每个项目单独一个目录，以项目名称命名。

当前已整理：

- [`FFS/`](FFS/README.md)：感知板工程、制造资料、1.3.15 固件、Windows 接收端、Android 采集端及核对记录。
- [`FFA/`](FFA/README.md)：语音板工程、制造资料、0.4.1 固件、FFV-transfer 音频服务及核对记录。

首批开源预览版：v0.1.0。目录结构和验证范围以各项目说明为准。

整理时可以按实际内容使用以下结构：

```text
project-name/
├── README.md       项目介绍、工具版本、制作与使用说明
├── hardware/       可编辑的原理图、PCB 和必要的元件库
├── firmware/       固件源码、构建和首次烧录说明
├── mechanical/     外壳与结构模型
├── docs/           照片、接线、BOM 和验证记录
└── LICENSE         项目许可证；不同部分可分别说明
```

目录按需要建立。项目说明中区分硬件版本与固件版本，并写清已经验证的功能、已知问题和仍在制作的部分。
