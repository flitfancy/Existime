# FFS · FIREFLY-SENSE 环境感知板

![FFS 环境感知板实物正面，白色 PCB。](08-实物照片/ffs-front.jpg)

FFS 环境感知板实物正面，白色 PCB。

一块用来记录身边环境变化的六通道感知板，集成温湿度、气压、多光谱、环境光与紫外线、VOC／NOx 和 CO₂ 传感器。各通道支持独立供电控制，通过 I²C 多路复用接入外部主控。

配合 ESP32-S3 主控、固件和可选屏幕，可以持续采集、显示环境数据，并通过 Wi-Fi／BLE 接入电脑、手机或 FlitFancy 网站。
