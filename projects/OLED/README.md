# OLED · 小屏幕接口板

30针OLED屏幕接口板的历史完整设计，原工程名称`screen_0921`。包含稳压/升降压、逻辑接口、复位与SPI/I²C装配选项；不是只有少数阻容的screen-lite简化设计，30针引脚定义也不同。

## 使用原件改版

复制对应`.epro2`后在兼容EDA版本中另存新工程，选择原有64件的PCB；原文件包含的辅助空白板不是另一套已验证硬件。本次完整保存源工程和原制造包，64个器件姿态及命名网络与制造记录已对账。

本次BOM/坐标为离线从原生数据提取，不冒充重新运行的原生BOM/CPL导出。原生冷导入、屏幕实物功能的本次重新验证尚未完成。

## 实装与返修记录

历史I²C实装记录为U2使用RT6150、L1使用HTMD-4020，并不装R20/R22/R24/R26。原始设计中的候选器件保留，实装差异见[装配记录](04-装配资料/实装和返修记录.md)。此前SCL/SDA交叉飞线属于返修建议，不能仅凭建议就当作已执行或已测通过。

作者已于2026-10-24确认除T1外全部纳入成功旧板归档，本项目现随 v0.6.0 公开；历史实装、返修记录和本次自动检查范围分开保留。
