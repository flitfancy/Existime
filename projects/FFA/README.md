# FFA · FIREFLY VOICE 双麦语音交互板

![FFA 语音交互板实装，绿色 PCB，搭配外壳与扬声器。](08-实物照片/ffa-assembled.jpg)

FFA 语音交互板实装，绿色 PCB，搭配外壳与扬声器。

一块基于 ESP32-S3 的双麦语音交互板，用来收听周围的声音，也播放音乐和语音回复。照片中是搭配外壳与扬声器的实装状态。

板子负责双麦采集、音频播放和 Wi-Fi 通信，电脑端负责回声消除、唤醒、语音识别与语音合成。配套服务提供独立网页、音乐播放和 OTA 升级，也可以通过 AstrBot 接入语音对话。高音量播放时的收音效果仍在完善。
