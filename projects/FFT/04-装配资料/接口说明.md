# FFT 接口与装配范围

本表取自当前原生工程读取。外部5V由X5V供电，USB调试JDBG不供电；SWE1为系统运行开关。

| 接口 | 物理脚 | 网络 |
| --- | --- | --- |
| X5V | 1 | EXT_5V_RAW |
| X5V | 2 | GND |
| X1 | 1 | FFS_5V |
| X1 | 2 | GND |
| X1 | 3 | FFS_SDA |
| X1 | 4 | FFS_SCL |
| X1 | 5 | FFS_INT_N |
| X1 | 6 | FFS_RESET_HOST_N |
| JDBG | 1 | USB_DM_PORT |
| JDBG | 2 | USB_DP_PORT |
| JDBG | 3 | GND |
| JDBG | 4 | BOOT_N |
| JDBG | 5 | MCU_EN |
| LCD1 | 1 | GND |
| LCD1 | 2 | LCD_CS_N |
| LCD1 | 3 | LCD_DC |
| LCD1 | 4 | LCD_SCK_PAD |
| LCD1 | 5 | LCD_MOSI_PAD |
| LCD1 | 6 | LCD_RESET_N |
| LCD1 | 7 | 未连接 |
| LCD1 | 8 | MAIN_3V2 |
| LCD1 | 9 | MAIN_3V2 |
| LCD1 | 10 | LEDA |
| LCD1 | 11 | LEDK |
| LCD1 | 12 | GND |
| FSP1 | 1 | MAIN_3V2 |
| FSP1 | 2 | FORCE_RAW_N |
| FSP1 | 3 | GND |
| FSP1 | 4 | FORCE_RAW_P |
| FSP1 | 5 | GND |

X3六孔为保留机械孔位，不装针、不作为电气接口。JDBG右侧第六孔无网络且为非金属化机械孔；其余五脚按D−、D+、GND、BOOT、EN使用。

LCD1当前保留元件面单面焊盘，0.5mm间距，12脚针序保持；排线双折装配方向已有设计核对，实际长度、补强、折弯半径、屏下空间及焊接可达性仍需用实物确认。压力传感器由主板正面法向受力，支撑、导向、接触片和限位需与样机一起标定。
