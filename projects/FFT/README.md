# FFT · 主控与显示终端

基于 ESP32-S3-WROOM-1-N16R8 的主控与显示板，连接彩屏、FFS 环境感知板，并带压力输入和唤醒按键。时间、天气与交互界面属于后续主程序目标。

当前作为**硬件预发布版 v0.4.0**公开：90×40mm、四角R2mm、双层PCB；66个器件、240个器件焊盘和7个独立孔位/焊盘，共247个焊盘对象。

## 电源与连接

外部5V从X5V输入，经电源路径送到RT6150主稳压，生成MAIN_3V2供主控、显示和压力采样使用。另一路由TPS25221控制FFS_5V，TMUX1511负责FFS总线/控制信号隔离。HSFPAR004A压力传感器直接贴装主板，经差分滤波接ADS1115。

JDBG为USB D−/D+、GND、BOOT和EN五线烧录接口，不提供主板供电；使用时仍需要X5V外部5V及SWE1开启。其第六个独立孔是无网络机械孔。X3六孔也只保留机械位置，不作电气对插。详细针脚见[接口说明](04-装配资料/接口说明.md)。

## 固件范围

`tactile-bench`只采集压力ADC、监测激励电压并提供零点/已知载荷标定，不初始化LCD，也不操作FFS支路。现有GPIO头文件已按当前原生引脚核对；原始源码在隔离目录通过PlatformIO编译，未烧录实板。

完整显示、时钟、天气和FFS联动主程序尚未收录。本项目不提供预编译BIN；测试程序的编译成功不代表整机功能完成。

## 当前检查与待验证项

原工程最新读取DRC为0，49网连通记录已保留；BOM和66行装配坐标与当前器件对应，Gerber元件姿态及焊盘连通关系已按网络别名核对。工程与制造包保持原始导出字节。详见[整理核对](05-核对记录/packaging-check.json)及[文件清单](MANIFEST.json)。

USB端口主干24mil、边距6.2mil，主控侧保留短6mil引出；实际板厂叠层/阻抗和首次USB烧录尚待验证。屏幕FPC双折干装、压力按压支撑/限位与标定、实际电源和整机验证仍未完成。
