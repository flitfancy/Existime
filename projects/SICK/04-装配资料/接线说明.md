# SICK 接口及验证范围

三个版本均为12V直流小电机的双NC限位自动换向。插件版和R3版以J1为电源、J2为电机、J3/J4为左右NC限位、SW1为电源开关接口；精确引脚网络优先查看对应版本`pin-net-from-native-source.csv`及原生原理图。

插件版采用VNH5019与AMS1117；R3贴片版采用VNH5019与HT7533；Lite采用DRV8876的PH/EN控制。相同接口名字不代表驱动器引脚或功率器件可互换。

坐标表说明：插件版和R3版来自原生PCB记录，保留原点/正负坐标并换算为mm；没有贴片厂旋转补偿。五个纯铜直焊接口不采购连接器时，以对应版BOM标记为准。

Lite完整引脚合同和逻辑网络表位于01-完整工程/lite-drv8876/生成源码/projects/sick_motor_reverser_r4_lite/。历史制造表坐标继续保留；另补2026-10-24原生CPL导出31行（mm），已核对器件位置与旋转。原生网络表见01-完整工程/lite-drv8876/文档源码/pcb-netlist.json。C1的借用器件元数据与实际库存电容差异见项目README。

Lite原生工程中的接口实际命名如下，按2026-10-24原工程读取，不能套用其他版本的接口位号：

| 接口 | 引脚1 | 引脚2 |
| --- | --- | --- |
| IN 电源 | +12V_IN | GND |
| MOTER 电机（保留原拼写） | MOTOR_A | MOTOR_B |
| L 左NC限位 | L_RAW | GND |
| R 右NC限位 | R_RAW | GND |
| SW 电源开关 | +12V_IN | +12V_SW |
